# Fake News Detection using Machine Learning

A machine learning and Natural Language Processing (NLP) project designed to detect and classify fake news articles. This repository contains the code, models, and documentation developed in partial fulfillment of the requirements for the degree of Bachelor of Science in Data Science (Session: Fall 2021–2025) at The Islamia University of Bahawalpur[cite: 2].

## 🚀 Project Overview
The rapid spread of misinformation requires automated, reliable detection methods. This project utilizes NLP techniques and supervised Machine Learning (ML) algorithms[cite: 2] to analyze text and determine the authenticity of news articles. 

The core of the project involves a deployed Flask-based web application featuring a Graphical User Interface (GUI)[cite: 2] that allows users to input news text and receive real-time predictions. The model achieves an 85% accuracy rate using Term Frequency–Inverse Document Frequency (TF-IDF)[cite: 2] vectorization and Logistic Regression. 

## 🛠️ Methodology & Tech Stack
* **Language:** Python
* **Web Framework:** Flask
* **Machine Learning:** Scikit-learn (Logistic Regression)
* **NLP Techniques:** TF-IDF Vectorization[cite: 2]
* **Data Processing:** Pandas, NumPy (processing Comma-Separated Values/CSV datasets)[cite: 2]

## 📂 Project Structure
The project workflow and documentation cover the following key phases[cite: 2]:
1. **Data Description:** Overview of the datasets used for training and testing[cite: 2].
2. **Methodology:** Data preprocessing, text cleaning, and feature extraction (TF-IDF)[cite: 2].
3. **Model Training & Evaluation:** Training the logistic regression model and evaluating performance metrics[cite: 2].
4. **Visualization and Insights:** Graphical representation of data distributions and model results[cite: 2].
